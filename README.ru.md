# MiMo-V2.6-Pro Uncensored на Maya

**MiMo-V2.6-Pro от Xiaomi — около триллиона параметров (основа с вырезанной цензурой «heretic»), с собственным зрением, 58–85 токенов/с на семи видеокартах и контекст 512K.**

Этот репозиторий — форк [Project Maya](https://github.com/mw00/project-maya) (MIT), движка, который запускает большие MoE-модели на своих видеокартах. MiMo Maya не знала. Здесь движок перенесён на **MiMo-V2.6-Pro** (архитектура `mimo2`: 70 слоёв, 384 эксперта, гибрид скользящего окна и полного внимания с sink-логитами, три слоя предсказания нескольких токенов (MTP), родное зрение), для неё собран калиброванный ~2-битный квант (300 ГБ, русский язык сохранён), а декодирование ускорено до повседневной работы: с 31 ток/с у первой рабочей сборки до 58–85 ток/с сейчас и с 20 до 38–40 ток/с на контексте 200K.

История скорости на этой машине: 31 ток/с (обычное декодирование) → 45 / 59 (один слой MTP, конвейерное окно) → 52 / 66 (все три слоя MTP, как модель обучали) → **63–69 / 85** при t = 0 (без вычислений на CPU, черновики из контекста). Длинный контекст: 7,4 ток/с на 70K → 32 (split-K внимание) → **38–40 на 200K** (внимание на тензорных ядрах + INT8-кэш).

## Что внутри

- **Порт движка на `mimo2`** (`src/core/glm_*.cu`, `src/kernels/cuda/mimo_*.cu`, `include/strata/kernels/mimo_*.hpp`): MiMo-V2.6-Pro внутри `Glm5Model` движка Maya, за флагом архитектуры, так что GLM-модели продолжают работать, а MiMo получает всё, что в Maya уже было: уровни памяти для экспертов, разбиение слоёв по видеокартам, сервер с API в стиле OpenAI/Anthropic и чат в браузере. Слои со скользящим окном держат кольцо на 256 строк, слои полного внимания — весь контекст.
- **Все три родных слоя MTP** (`STRATA_MIMO_MTP3=1`): слой *k* угадывает токен на глубине *k* из скрытого состояния основной модели — именно так MiMo обучали (если гонять один слой по цепочке трижды, глубины 2–3 почти бесполезны: 16 % / 3 % против 56 % / 54 % на эталоне `transformers`). Черновики проверяются одним окном, проходящим через все семь видеокарт.
- **Спекулятивная выборка** черновиков при температуре > 0 (`STRATA_GLM_SPEC_SAMPLE=1`) **выключена в рабочем конфиге**: вместе с черновиками из контекста она портит длинные ответы при температуре 1 (строки повторяются, слова разваливаются; найдено 19.10.2026 на длинных русских сценах). По отдельности оба механизма чисты; исправление сочетания в работе. Без неё выборка совпадает с обычной (тот же текст при том же seed).
- **Черновики из контекста** (`STRATA_GLM_LOOKUP=1`): если текст повторяет что-то из диалога, до 7 токенов выдаются за один шаг.
- **Пакетное чтение промпта** для `mimo2` (внимание со скользящим окном и sink на тензорных ядрах, куски по 4096) и конвейерное окно для коротких кусков (новое сообщение в чате).
- **Внимание декодирования на тензорных ядрах** для слоёв полного внимания (16 голов запроса одной KV-головы — один тайл `mma`), упирается в пропускную способность памяти даже на 200K; **INT8-кэш K/V** для этих слоёв (`STRATA_MIMO_KV8=1`) — вдвое меньше памяти и трафика.
- **Контрольные точки диалога**: кольца слоёв со скользящим окном на начале последнего сообщения хранятся в RAM, так что другой вопрос к длинному диалогу читает только свои токены.
- **Родное зрение** (`tools/mimo/mimo_vision.py`): собственный vision-трансформер чекпойнта на первой видеокарте — движок одалживает ему видеопамять на время кодирования картинки; заранее прогретый процесс запускает кодировщик на каждую картинку через fork.
- **Хук вектора отказов** (`STRATA_GLM_ABLATE*`, в прилагаемом конфиге выключен): вычитает направления отказа из остаточного потока; вектор для MiMo ещё в разработке (см. ниже).
- **Инструменты квантования** (`tools/mimo/`): калибровочная статистика с русским текстом, imatrix/GPTQ, исправление слоёв MTP, снятие и вычисление направлений отказа, эталонные скрипты, бенчмарки.
- **Тесты**: внимание декодирования и чтения промпта против эталонов в FP64 (`tests/mimo_decode_attn_test.cu`, `tests/mimo_prefill_attention.cu`), загрузчик геометрии `mimo2` (`tests/mimo_geometry_test.cpp`).

## Исправления 20.10.2026 (обновитесь, если клонировали раньше)

- **Агентные сессии могли превращаться в мусор.** Если новый разговор одного клиента обрывался посреди чтения промпта, движок уже сбросил кэши, но оставлял запись о снимке прежнего разговора; следующий ход того разговора восстанавливал кольца скользящего окна поверх обнулённых кэшей полных слоёв и с первого токена выдавал бессмыслицу (выдуманные результаты инструментов, несуществующие инструменты). Теперь сброс аннулирует снимок. Воспроизведено точной последовательностью запросов (2 из 2 сломаны до, верно после).
- **`<think>` утекал в размышления.** MiMo сама открывает размышление; сервер передавал этот тег дальше, агенты возвращали его в истории, и модель удваивала его каждый ход. Теперь сервер срезает его в ответе и в возвращённой истории.
- Спекулятивная выборка выключена в рабочем конфиге (см. ниже).

## Быстрый старт

### 1. Собрать движок

Тот же установщик, что у Project Maya (Linux x86-64, драйвер NVIDIA, CUDA 12.x или 13, Python 3.10+; см. [требования Project Maya](README.project-maya.md)):

```bash
git clone https://github.com/denisnotes357-prog/MiMo-V2.6-Pro-Uncensored-Maya
cd MiMo-V2.6-Pro-Uncensored-Maya
./setup.sh
```

Он создаст Python-окружение `.venv`, скачает ggml на закреплённом коммите llama.cpp и соберёт `build/strata`. Когда он предложит скачать модель, ответьте **no** — он скачал бы другую модель. Пересборка позже: `cmake --build build -j --target strata`. Порт собран и проверен для `sm_80` (A100) и `sm_89` (RTX 4090).

Для картинок башня зрения работает на PyTorch в том же окружении:

```bash
.venv/bin/pip install torch transformers safetensors pillow
```

### 2. Скачать модель

```bash
pip install -U huggingface_hub
hf download nofacedfl/MiMo-V2.6-Pro-Uncensored-Maya --local-dir models/MiMo-V2.6-Pro-Uncensored-Maya
```

Около 302 ГБ: семь шардов GGUF, `pack/` (индекс движка по этим шардам, плотные веса и токенизатор; шарды он ищет рядом с собой) и `vision/` (башня зрения).

### 3. Запустить

```bash
tools/mimo/run-mimo-pro.sh
```

- Чат в браузере: http://127.0.0.1:8098/
- API в стиле OpenAI: `http://127.0.0.1:8098/v1/chat/completions`, модель `mimo-pro` (картинки — как `image_url`)
- API в стиле Anthropic: `http://127.0.0.1:8098/v1/messages` (для Claude Code и других агентов: `ANTHROPIC_BASE_URL=http://127.0.0.1:8098`)
- Размышления: `reasoning_effort` = `none` / `low` / `high` (по умолчанию) / `max` или `chat_template_kwargs: {"enable_thinking": false}`
- Монитор скорости: http://127.0.0.1:8098/#monitor

Загрузка занимает 2–3 минуты. Перед запуском остановите другие задачи на видеокартах; Ctrl+C останавливает модель.

### Под свои видеокарты

Прилагаемый конфиг рассчитан на 7 видеокарт с ~320 ГБ видеопамяти (видеокарта 1 той машины не используется). Важные ключи:

| Ключ | Что значит |
| --- | --- |
| `gpu`, `CUDA_VISIBLE_DEVICES` | видеокарты вдоль конвейера слоёв |
| `STRATA_GLM_SPLIT=11,22,33,44,53,61` | первый слой каждой следующей видеокарты (двум A100 достаётся меньше слоёв) |
| `--max-context 512000` | с `STRATA_MIMO_KV8=1`; на этой машине ~200–330 экспертов тогда живут в RAM (строка `glm stat`: `vram`/`ram`) |
| `STRATA_MIMO_MTP3=1`, `STRATA_GLM_MTP_PIPE=1`, `STRATA_GLM_MTP_DRAFT=7` | родные три слоя MTP, черновики проверяются конвейерным окном |
| `STRATA_GLM_SPEC_SAMPLE=0`, `STRATA_GLM_LOOKUP=1` | спекулятивная выборка выключена (с lookup портит длинные ответы); черновики из контекста включены |
| `STRATA_GLM_CPU_LANE=0`, `STRATA_GLM_PREFILL_CPU=0` | эксперты не считаются на CPU — здесь это быстрее (жадный вывод всё равно слегка меняется от запуска к запуску на конвейере из семи карт) |
| `STRATA_MIMO_KV8=1` | INT8-кэш K/V для 10 слоёв полного внимания |
| `vision.gpu: true` | башня зрения на первой видеокарте (движок одалживает ей 5,7 ГБ на каждую картинку); `"device": N` — на отдельной карте, без одалживания |
| `STRATA_MIMO_DEV=1` | путь `mimo2` помечен экспериментальным; без этого ключа движок его не запустит |

Если видеопамяти меньше, уровни памяти Maya всё равно работают: эксперты, которые не влезли, берутся из RAM (медленнее).

## Отказы и вектор отказов

Веса — [`pqhaz/MiMo-V2.6-Pro-MOPD-heretic`](https://huggingface.co/pqhaz/MiMo-V2.6-Pro-MOPD-heretic) (MIT): MiMo-V2.6-Pro-MOPD от Xiaomi с двухэтапной направленной абляцией отказов в выходных проекциях внимания. В нашем кванте модель отвечает на большую часть запросов, от которых отказывается оригинал, но всё ещё отказывает в **24 из 40** запросов JailbreakBench.

**Вектор отказов во время генерации — в разработке и в релиз не входит.** Мы измерили шесть направлений отказа на слой (вредные и безвредные инструкции, `tools/mimo/capture.py`, `derive.py`) и вычитали их при генерации. Отказов стало 1–5 из 40, но проверки шире подсчёта отказов показали два побочных эффекта:

- если вектор работает на каждом токене, длинные русские ответы (1000+ токенов) начинают зацикливаться и выдумывать слова (ограничение первыми 64 токенами ответа это исправило, `STRATA_GLM_ABLATE_TOKENS`);
- но и тогда модель перестаёт говорить «не знаю»: на вопросы о несуществующих людях, событиях и фильмах она честно ответила в **1 из 10** случаев с вектором против **6 из 10** без него, а в остальных уверенно выдумывала подробности. У отказа и признания незнания общее направление.

Следующая версия будет снимать отказы без этого эффекта и проверяться на длинных ответах, выдумках и агентных задачах, а не только на числе отказов. Хук в движке остаётся (`STRATA_GLM_ABLATE`, `_SCALE`, `_LAYERS`, `_TOKENS`) для экспериментов.

Сам квант откалиброван с ~14 % русского текста: прежний квант, откалиброванный только на английском, давал на русском перплексию 44,8. Подробности, цифры и тупики — в [docs/HOW-IT-WAS-MADE.md](docs/HOW-IT-WAS-MADE.md).
